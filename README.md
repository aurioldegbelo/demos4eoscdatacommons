This repository provides resources for integrating NFDI4Earth resources into the EOSC Data Commons project.

- [x] Notebook to harvest all datasets from the [NFDI4Earth Knowledge Hub](https://knowledgehub.nfdi4earth.de/) as JSON
- [ ] Tool to reuse one example dataset from the Earth System Sciences, after discovery through the matchmaker 
- [ ] Examples of queries for the [EOSC Matchmaker](https://www.eosc-data-commons.eu/service/eosc-matchmaker)
- [ ] Examples of user stories for the use of the EOSC Data Commons services
